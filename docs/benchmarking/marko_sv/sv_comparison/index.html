Filter metrics explained (QD, DP, SOR)

GATK VariantFiltration populates the FILTER column with PASS or named filter tags but does not remove any variants. This is a soft filter fallback used when VQSR cannot run (no known variant resources for custom genomes).

Column Metric Filter Threshold Interpretation
QD Quality by Depth QD < 2.0 → QD_filter QUAL score / total depth. Low QD = weak evidence per read. Higher is better.
DP Read Depth — (no filter) Total reads at this position (INFO/DP, cohort-level). Shown for context only.
SOR Strand Odds Ratio SOR > 3.0 → SOR_filter Strand bias test. SOR > 3.0 = variant seen disproportionately on one strand (possible artifact). Lower is better.
HC Filter FILTER column Combined result PASS = passes all filters. Otherwise shows which filter(s) flagged the variant (e.g. QD_filter, SOR_filter, MQ_filter).

Other soft filters applied (not shown as columns): FS > 60.0 (FS_filter), MQ < 40.0 (MQ_filter), MQRankSum < -12.5, ReadPosRankSum < -8.0, QUAL < 30.0. INDEL thresholds are more lenient (FS > 200, SOR > 10).

Thresholds follow GATK best practices for human data. See conf/modules/joint_germline.config for full configuration.

Key Findings

100% large deletion recall. All 4 breseq deletions (776 bp – 6,790 bp) detected by both Manta and TIDDIT with ≤8 bp coordinate difference. SURVIVOR consensus confirms all 4.
100% SNP/InDel recall. All 11 breseq SNPs and small indels detected by HaplotypeCaller. 10/11 pass soft quality filters (PASS). 1 flagged by SOR_filter.
rpoS nonsense mutation soft-filtered. G2867455A (rpoS, W → Stop) has SOR=3.014, barely above the 3.0 threshold. QD=29.56 is excellent (threshold: 2.0). This is a biologically important mutation frequently seen in E. coli lab evolution. Consider relaxing SOR threshold or reviewing this filter for haploid organisms.
MOB insertions are breseq-unique. 3 IS-element mobilizations (2×IS2, 1×IS5) detected only by breseq. This is expected: standard SV callers cannot resolve insertions of repeat elements already present elsewhere in the genome. breseq uses assembly-based junction detection.
yAMP found additional SVs not in breseq. A 9,049 bp deletion at position 2,169,285 (Manta + TIDDIT consensus) and an inversion at ~1,207,789 were detected by SV callers but not breseq. These may represent real structural variants or alignment artifacts worth investigating.
