# CNVKit Ploidy Experiment Results

**Date**: 2026-05-21

**Input**: Ottilie pilot `.md.cns` segmentation files (ploidy-independent)

**Varied**: `cnvkit.py call --ploidy N` + `cnvkit.py export vcf --ploidy N`

**Image**: `quay.io/biocontainers/cnvkit:0.9.10--pyhdfd78af_0`


## Key question

CNVKit upstream steps (batch → coverage → fix → segment) have **no --ploidy flag**.
Only `call` and `export vcf` accept it. How does ploidy change the CN integer
assignment and VCF output for the same underlying log2 ratios?
