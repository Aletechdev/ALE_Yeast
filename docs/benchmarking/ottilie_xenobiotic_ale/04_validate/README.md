# 04_validate — validation & benchmarking tooling

Scripts live flat here; each analysis writes into its own results directory. Convention:
`run_*.sh` = launcher (records exactly how a result was produced), `*.py` = the analysis itself.
Committed results are the summary tables and notes; bulky per-sample intermediates are left
untracked and regenerated by re-running the launcher.

## SNV / INDEL

| Script | Purpose | Results |
|---|---|---|
| `snv_indel_concordance.py` | Score calls against the 1,405-mutation truth set (Ottilie Sup. Data 4); `--pass-only` measures the soft filter's cost | `tier2_results/`, `pilot_results_v2/` |
| `validate_all.py` | Full suite (SNV/INDEL + CNV + SV) → `VALIDATION_REPORT.md` | `pilot_results*/`, `tier2_results/` |
| `investigate_missed_snv_indel.sh` | Why a truth mutation was missed (depth/MAPQ at the site) | prints |
| `run_snv_indel_concordance_tier2.sh`, `run_validate_all_{pilot_v2,tier2}.sh` | Launchers for the above | |

## SV

| Script | Purpose | Results |
|---|---|---|
| `run_sv_mode_series.sh` | Run one cohort through **all three Manta modes** (per-sample / joint / joint+high-sensitivity) | `output_*_{persample,jointdefault,joinths}` |
| `compare_sv_pass_tables.py` | Score those merged pass tables — parent presence, clone-specific rows, and which are **false** (engineered-cassette loci) | feeds `manta_joint_at_scale/REPORT.md` |
| `manta_joint_vs_single.py` | Per-record audit of joint vs per-sample Manta (what the joint call loses/gains) | `manta_joint_at_scale{,_hs}/` |
| `run_manta_joint_at_scale.sh` | Launcher for the 86-sample audits | same |
| `run_manta_joint_audit_pilot.sh` | The 4-sample mode sweep (`default`/`exome`/`noedgecap`/`both`/`cap30`) | `pilot_results_v2/manta_joint_audit/` |
| `sv_cohort_matrix.py`, `sv_characterization.py`, `run_sv_matrix_pilot.sh` | Cohort SV matrix + event characterisation | `pilot_results*/` |
| `sv_merge_bench/` | SVDB merge-recipe benchmark (chose the current chain) | in-dir NOTES.md |

**Start here for SV mode questions:** [`manta_joint_at_scale/REPORT.md`](manta_joint_at_scale/REPORT.md)
(4/16/48/86-sample comparison) and the user-facing summary in
[`docs/variant-calling/manta/manta_calling_modes.md`](../../../variant-calling/manta/manta_calling_modes.md).

## Shared

`sample_names.py` — maps paper clone names ↔ pipeline sample names (`data/ottilie/sample_name_dictionary.csv`).
`VALIDATION_PLAN.md` — what validation is expected to cover. `MUTATION_REPORT_PLAN.md` — report design notes.

## Results directories

`pilot_results/` (4-sample, superseded) · `pilot_results_v2/` (4-sample, current — `NOTES.md` holds the

audits; `summary.tsv` + `REPORT.md` tracked, per-sample `details_*.tsv` not).
