ALE Variant Inspector

This VCF contains all soft-filtered variants (FILTER column annotated, no variants removed). Defaulting to VCF_FILTER = PASS. Clear the filter to view all variants including flagged ones. Row counts may differ from the dashboard summary due to multi-allelic splitting (bcftools norm -m-) and VCF post-processing. To be validated before release.
Cohort-level report. Click any per-sample GT or VAF cell (non-reference genotypes only, i.e. GT≠0) to open the per-sample IGV report at that locus. Per-sample reports contain only variants passing hard-filter criteria: FILTER=PASS, GQ≥20, DP≥8, AF≥0.90 (clonal) or ≥0.05 (population).
