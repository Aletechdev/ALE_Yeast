### SV/CNV Table-Only Decision ✅ (2026-06-10)
- **Decision**: Disable IGV alignment view for all SV/CNV reports (CNVKit, Manta, TIDDIT)
- **Rationale**: igv-reports embeds a fixed reference window (`--flanking 500` = 250bp per side). Multi-kilobase SV/CNV events cannot be meaningfully viewed in this window. See [igv-reports #100](https://github.com/igvteam/igv-reports/issues/100).
- **Implementation**: Removed CRAM from `--tracks`, stripped session data, added yellow info banner directing users to IGV desktop
- **User guidance**: Download VCF + CRAM and open in [IGV desktop](https://igv.org/doc/desktop/) for full-genome SV navigation

### TIDDIT Report Integration ✅ (2026-06-10)
- Added TIDDIT per-sample reports to `IGVREPORTS_SV_CNV` process
- FORMAT columns: `GT DV RV` (paired-end + split-read support counts)
- Linked from index.html TIDDIT count column (click-through)

### Legend & Documentation Improvements ✅ (2026-06-10)
- **VCF_FILTER**: Clarified as cohort-level soft filter (INFO fields aggregated across all samples)
- **INFO fields in per-sample reports**: AC/AF/DP/QD/MQ labeled as "Quality (cohort)" — these are stale values from joint calling, not recalculated after `bcftools view -s` splitting (except AC/AN). Users directed to FORMAT columns (VAF, sample:DP, GQ) for sample-specific values.
- **Sample FORMAT columns**: Fixed `{sample}:DP` categorization (was under "Quality", now under "Sample" via `sampleFormatDescriptions`)
- **IGV Alignment Colors**: Added comprehensive color guide to per-sample HC reports (gray=normal, red=large insert, blue=small insert, colored=inter-chromosomal, lighter=low MQ)
- **Edge Artifact**: Documented that colorful stripes at IGV view edges are display artifacts from reads extending beyond the embedded reference window

### Flanking Parameter ✅ (2026-06-10)
- `--flanking 500` for all report types (igv-reports divides by 2 internally → 250bp per side)
- Trade-off: smaller file size vs edge artifacts for reads extending beyond the window
- Documented as known limitation in the IGV color guide legend

### Nice-to-Have

- **CSV/VCF download links**: The SV Ensemble table has download buttons for CSV and VCF files, but the HTML `download` attribute only works over HTTP — when viewing via `file://` protocol, clicking opens the file in a new browser tab instead of triggering a save dialog. Fix options: (1) serve via local HTTP server, (2) use JavaScript Blob-based download, (3) accept current behavior for local use.
- **Benchmarking re-run**: Update adipic acid benchmarking scripts from AF 90% → 80% threshold (see `docs/benchmarking/adipic_acid_ale/README.md` TODO section)
- **`COUNT_VARIANTS` cleanup**: Remove dead Nextflow process and `--variant-counts-json` parameter from `generate_demo_reports.nf` (replaced by MultiQC source)
- **Fix GENERATE_INDEX race condition**: The `GENERATE_INDEX` process in `generate_demo_reports.nf` runs `generate_index.py` before creating `samples/` symlinks, so the NF-generated index always has null `igv_link` values (sample clickthrough links broken). Currently worked around by a standalone `generate_index.py` call at the end of `generate_ottilie_reports.sh`. Fix: move symlink creation before the Python call inside the NF process, or pass sample report paths as explicit process inputs.
